# Hollis & Row – E-commerce Admin Panel (Next.js)

## Run it
1. Unzip and open the folder in VS Code
2. Open the terminal (Ctrl + `) and run:

   npm install
   npm run dev

3. Visit http://localhost:3000

Requires Node.js 18.17 or newer.

## Where things live
- app/globals.css      colors (CSS variables), layout and all styling
- lib/data.js          all demo data (orders, products, revenue)
- components/          one file per section of the dashboard

To change the palette, edit the variables at the top of app/globals.css.
